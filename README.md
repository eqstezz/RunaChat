# RunaChat Online — запуск

## 1. Создай Firebase-проект
1. Открой Firebase Console и нажми **Create a project**.
2. В проекте добавь приложение **Web** (`</>`).
3. Скопируй объект `firebaseConfig` в файл `firebase-config.js`.

## 2. Включи Realtime Database
1. Firebase Console → **Build → Realtime Database → Create Database**.
2. Выбери ближайший регион.
3. Открой вкладку **Rules** и вставь содержимое `database.rules.json`, затем нажми **Publish**.

## 3. GitHub и Render
1. Загрузи содержимое этой папки в новый GitHub-репозиторий.
2. Render → **New → Blueprint** → выбери репозиторий.
3. После деплоя открой выданную ссылку.

## Проверка
Открой ссылку в двух разных браузерах/телефонах, зарегистрируй два аккаунта, создай публичную комнату и подключись к ней с обоих устройств.

## Важно
Текущая система входа сохранена без изменения: пароли и служебные коды обрабатываются клиентским JavaScript. Это подходит для тестового проекта, но не для настоящего приватного сервиса. Для безопасной публикации следует отдельно перейти на Firebase Authentication и закрытые Security Rules.
